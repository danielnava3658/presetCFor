# 📂 Centro de Prácticas en C: Fundamentos de Programación

¡Bienvenido/a al repositorio oficial de ejemplos prácticos para la clase de **Fundamentos de Programación**! 

Este espacio ha sido diseñado como un centro de recursos y almacenamiento de código en **C** con el propósito de centralizar todos los ejercicios, prácticas y ejemplos vistos en clase. Su objetivo principal es servir como una guía de consulta rápida y un material de apoyo interactivo para facilitar el aprendizaje de la lógica de programación y la sintaxis del lenguaje C.

---

## 🎯 Propósito del Repositorio

* **Centralizar el aprendizaje:** Tener en un solo lugar todos los programas prácticos desarrollados a lo largo del curso.
* **Fomentar la experimentación:** Proveer código funcional, comentado y fácil de entender para que puedas modificarlo y probarlo por tu cuenta.
* **Servir como referencia:** Ayudar a resolver dudas comunes sobre sintaxis, estructuras de control, manejo de memoria y modularización.

---

## 📁 Estructura del Repositorio

Los códigos fuente están organizados por temas y nivel de complejidad para un acceso más intuitivo:

```text
/
├── 01_introduccion/        # Estructura básica, printf, scanf y tipos de datos
├── 02_condicionales/       # Uso de if, else, switch y operadores lógicos
├── 03_ciclos/              # Bucles while, do-while y for
├── 04_arreglos/            # Vectores (unidimensionales) y matrices (bidimensionales)
├── 05_funciones/           # Modularización, paso por valor y por referencia
├── 06_apuntadores/         # Introducción a punteros y direcciones de memoria
└── 07_archivos/            # Lectura y escritura de archivos en C
```

---

## 🚀 ¿Cómo usar este material?

1. **Clona o descarga** este repositorio en tu computadora para tener acceso local a todos los archivos `.c`.
2. **Abre el código** en tu entorno de desarrollo favorito (como Code::Blocks, VS Code, CLion o directamente en tu terminal con GCC).
3. **Compila y ejecuta** los ejemplos. Te recomendamos modificar los valores de las variables y experimentar con el código para observar cómo reacciona el programa.

### Ejemplo rápido de compilación por terminal (GCC):
```bash
gcc nombre_programa.c -o programa
./programa
```
